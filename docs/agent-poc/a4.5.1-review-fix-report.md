## 二、 真实生成来源审计与段级继承衰减机制

为坚守数据科学的诚实性，杜绝“将段落级标注虚报为逐镜头逐帧独立视觉分析”，本系统在 `provenance` 中正式确立了两级粒度规范：

```mermaid
flowchart TD
    A["镜头输入 (Scene Item)"] --> B{"镜头时长与类型判定"}
    B -->|时长 >= 3.5s 或 段落主镜头| C["independent_keyframe (独立代表帧分析)"]
    B -->|短正反打微切镜头 < 3.5s| D["segment_inherited (段级继承分析)"]
    C --> E["提取真实代表中间帧 (sample_frame_refs)"]
    C --> F["高置信度 (confidence: 0.90 ~ 0.95)"]
    C --> G["source_segment_id: null"]
    D --> H["继承所属母段落环境与基础角色 (source_segment_id)"]
    D --> I["置信度衰减 (confidence: 0.76 ~ 0.82)"]
    D --> J["保留代表帧引用 (sample_frame_refs)"]
```
