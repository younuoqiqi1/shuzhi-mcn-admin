## 三、 Consistency Validator (人物一致性校验器) 落地

### 3.1 规则实现
在 [`src/perspective/providers/perspective-provider.mjs`](../../src/perspective/providers/perspective-provider.mjs) 中导出 `validatePerspectiveConsistency(interpretation, candidate)`：
1. **别名网络匹配**：精准识别解读中提及的关键人物；
2. **在场性校验**：若人物在当前镜头出镜，判定合法；
3. **上下文修饰词豁免**：若人物未出镜，但解读中带有明确修饰词（如“口中提及”、“借题”、“未在场但作为背景”等），判定合法；
4. **违规拦截**：若既未在场又无说明，直接判定不一致：
   - 打上 `risk_flags: ["unsupported_character_reference"]`；
   - 强行置 `supports_claim = "false"`，`recommended_use = "reject"`；
   - 惩罚性扣减视角得分 0.35 分。
