## 一、治理背景与根本原因回顾

在 A8 阶段，用户亲自观看成片后指出了关键 Content Grounding 失败：
1. **Topic B**：“没看到金条的台词，不成立”；
2. **Topic A**：“有重复镜头，也没有副站长就是你这句台词”。

经 Root Cause 审计，根本症结在于：
1. **L1 物理事实存在大粗粒度先验污染**：历史脚本按时间粗暴套用情节映射，导致 `scene_0059`（陆桥山与余则成楼梯谈话）被虚构出吴敬中；
2. **机械切片切断了连贯台词**：原声切片只截取了前几秒，导致“副站长就是你”（310.5s）和“两根金条”（2019.5s）刚好落在切片边界外；
3. **Director 编排层缺乏防重复镜头强校验**：导致 Topic A 出现重复引用同一镜头；
4. **VMV 消费端残留硬编码伪造字幕**：`render.py` 内部存在固定字幕注入逻辑，掩盖了底层台词不齐的问题。

- 重构 [`src/evidence/scripts/build_canonical_evidence.mjs`](file:///Users/yoyotaozhou/Documents/antigravity/intelligent-pasteur/shuzhi-mcn-admin/src/evidence/scripts/build_canonical_evidence.mjs)：

  - 确证 `scene_0059`（556.52s - 573.24s）出镜人物仅为 `['余则成', '陆桥山']`，绝对不含吴敬中；
  - 确证 `scene_0193` 物理空间为田野小路送别，绝无片尾演职员字幕污染。

### 2. 引入连续对话单元扩展 (Dialogue Span Expansion)
为避免连贯话语被镜头切点机械腰斩，在 L1 独立构建对话扩展单元：

- `unit_dial_promotion_01` (00:10:47.280 - 00:11:01.000, 13.72s): 完整涵盖“**今天值得庆祝 一为收复延安 二 则成晋升为中校副站长**”；
- `unit_dial_celebration_01` (00:11:01.000 - 00:11:15.000, 14.00s): 完整涵盖“**余副站长 恭喜呀 以后多多关照啊 同甘共苦 同甘共苦**”。

### 3. 构建五维全息生产门禁 (ProductionGroundingGate)
创建 [`src/director/production-grounding-gate.mjs`](file:///Users/yoyotaozhou/Documents/antigravity/intelligent-pasteur/shuzhi-mcn-admin/src/director/production-grounding-gate.mjs)，设置 5 项严苛标准：
- **Temporal Grounding**: 时码区间必须严格在 0 ~ 2702.013s 内且 `planned_duration == source_out - source_in`；
- **Dialogue Grounding**: 声称保留原声或原声主导的段落，台词必须在源视频该区间真实存在（若声称包含“副站长就是你”或“两根金条”而实际缺失，坚决阻断）；
- **Visual Grounding**: 关键人物（如吴敬中、余则成、谢若林）必须真实出镜；
- **Semantic Grounding**: 必须达到 Level 4（语义证据吻合）或 Level 5（导演意图吻合）；
- **Editorial Grounding**: 同一成片默认严禁重复使用相同 `retrieval_unit_id`。

### 4. Director 防重复镜头强校验
在 [`src/director/director-evidence-validator.mjs`](file:///Users/yoyotaozhou/Documents/antigravity/intelligent-pasteur/shuzhi-mcn-admin/src/director/director-evidence-validator.mjs) 中增加 `seenUnitIds` 查重机制。成片若出现重复镜头且未声明 `allow_repeat=true`，立即抛出 `DirectorValidationError`。

### 5. 消费端彻底剔除假字幕硬编码
在 `video-moment-validation` 的 [`src/vmv/render.py`](file:///Users/yoyotaozhou/Documents/video-moment-validation/src/vmv/render.py) 中，完全删除了历史遗留的假字幕硬编码（原 335–343 行）。渲染端字幕现在严格来源于分段中的真实 `original_dialogue_text` 或 `narration_text`。代码已通过 55 项 pytest 并 push 至远程。

### 6. 真实源片抽帧证据链 (Evidence-to-Frame Proof)
使用原生 FFmpeg 从 720p 真实片源 `qianfu_ep18.mp4` 针对 7 个生产镜头各抽取 3 张高清代表帧（共 21 张 JPG，存放于 `outputs/grounding_proofs/frames/`），并组装成独立交互式 Storyboard HTML 页面。
