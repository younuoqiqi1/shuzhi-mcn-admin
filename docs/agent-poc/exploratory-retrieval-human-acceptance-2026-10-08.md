## 测试二：Q5 原文检索

原文与仓库中的 [queries.json](limited-x2-existence-gold/queries.json) 一致：

> 找一段短发、戴耳坠、穿红色花纹旗袍的女人，在室内掏出手枪朝戴眼镜、穿深色中山装的男人开枪的镜头。

### 出题背景

本地出题提案将作者角色记录为 `independent source-bound query author`，没有注明具体执行模型。Q5 最初拟作 `hard_negative`：人物外观取自原片采样，增加采样中未观察到的掏枪射击动作，用于检查是否把外观相似误当作完整匹配。它不是用户提出的真实剪辑业务需求。

提案同时说明，采样未见不能保证整集不存在。后续 [正式协议](limited-x2-retrieval-probe-v1.md) 已取消 Q5 必为负例的预设，五条题均按中性存在性问题处理。本轮没有恢复旧负例预设。

### 检索结果与用户反馈

在现有描述中未找到完整支持 Q5 的记录。语义阅读没有找到指定女子掏枪并朝指定男子射击的描述；枪、射击、开火及相关英文词的补充检索也未命中。此结果只涉及已有描述，不能推出原片事件不存在。

返回的相似参考是连续的 `shot_B0025` 与 `shot_B0026`，原片 **16:50.88–16:59.40**（1010.88–1019.40 秒）：

| 要求 | 相似片段所支持的内容 |
|---|---|
| 女子外观、耳坠、红色花纹旗袍 | 描述及代表帧有对应线索 |
| 室内、戴眼镜的男子 | 描述及代表帧有对应线索 |
| 深色中山装 | 未获支持；描述及代表帧更接近深色西装与白衬衫 |
| 掏枪并朝男子射击 | 没有支持该动作的描述或已查看画面证据；未作为匹配返回 |

用户指出“没有找到并不能说找错，没有也是对的”，并认可这个相似片段作为参考的价值。对话随后明确：结果应表述为“未找到完整匹配，以下是相似参考”，而非把参考片段当作射击命中。用户再次询问是否通过时，按这一人工验收口径记录 **Q5 探索性检索人工验收通过**。

这个口径是在本次讨论中确认的，不冒充预注册评分。通过的内容是结果呈现、差异说明和相似参考的实用性；并未验证“整集没有目标事件”这一事实判断，也未测得漏检率或正确拒答率。

## 状态纠正与正式测试的边界

早先把“没有完整匹配”直接说成“Q5 未通过”不准确，本记录纠正该表述：

- 若原素材确实没有目标事件，明确返回无匹配可以是正确结果。
- 若原素材存在目标事件而未找到，则可能是漏检或输入覆盖不足。
- 若将交谈片段报成掏枪射击，则是误匹配。
- 本次没有完成整集存在性核验，不能决定前两种情况；本次人工验收通过不等于正式 Q5 评分通过。

正式 [Limited X2 Probe](limited-x2-retrieval-probe-v1.md) 的 Gold、输入隔离、首次输出封存及评分要求保持原样。本轮有对话上下文和人工反馈，不属于盲检索；正式协议中的“检索未执行”仍指正式运行，并不否认本次另行记录的探索性检索。未运行 Q1–Q4 正式测试或下游视频生产。
