# Human Anchor 快速标注规范

## 用途与盲法

Human Anchor 是一次性 POC / 系统能力校准成本，不参与任何单集素材 Ingest。标注者直接观察原始帧/视频及必要原声音频，必须完全盲于 Gemini Evidence、Codex Review、AI Judge 和其他模型输出。不要推断剧情、真实身份、关系、动机、情绪或叙事意义。看过这些样本的预测或 Review 的人不能标注本 Anchor。

## 30 分钟硬预算

固定 30 个既有 Shot，不新增或重抽样；页面另显示 20 组从这 30 个派生的人物截图比较，不改变 Anchor Manifest。任务最多 30:00。建议每个 Shot 快速选择约 35 秒，每组人物比较约 15 秒，其余用于跳转、必要播放及修正。达到 30 分钟时页面锁定，不得延长补标。

## 字段

- 镜头边界：可用 / 不可用 / 不确定。
- 人物数量：0 / 1 / 2 / 3 / 4+ / 不确定。
- 人物一致性：并排看固定 Pair 的两张原始 50% 帧，点击两边要比较的人，再选同一人 / 不同人 / 不确定。不得维护 P01/P02 或填写人物姓名；无法可靠选择时选不确定。
- 场景：室内 / 室外 / 车辆内 / 过渡或无法归类 / 其他 / 不确定。
- 动作：可多选坐/站、移动、说话/交流、操作物体、其他、无明显动作、不确定。
- 物体：可多选家具、容器、纸张/文档、设备/工具、交通工具、食物/饮品、其他、无关键物体、不确定。选择“其他”时才可选填最多 24 字。
- 语音与 Speaker：选择可辨语音 / 无可辨说话 / 不确定；再选画面中人物 / 画外音 / 不确定。如为画面中人物，点击原帧上的人物位置。不要逐字转写对白。
- 每个必需字段都要明确选择；无法确定时点击“不确定”，不要留空或猜测。仅在语音判断不清时播放原声。

## 自动保存与计时

页面以 PBKDF2-SHA256 + AES-256-GCM 自动保存到浏览器 IndexedDB；仅保存加密答案密文与答案的 SHA256 commitment，不保存口令或答案明文。旧记录无法解锁时，可用“新建空白标注并开始”创建独立记录；原密文保留、不覆盖，旧答案不会自动迁入新记录。请使用专属的本地浏览器账户，不向 Agent 提供口令。页面从解锁后开始记录可见且聚焦时的活跃时间、每项任务耗时、每个 Shot 的归因时间和全任务总时长；页面切到后台、窗口失焦或关闭期间暂停计时，恢复后继续。30 分钟为硬上限。加密备份存放在 Git 仓库外。
