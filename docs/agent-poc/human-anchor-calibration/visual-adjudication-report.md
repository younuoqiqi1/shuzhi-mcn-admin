## Person count：时间范围与局部身体

10个差异中，4项裁为分类定义歧义。原定义列出人数类别，却没有指定峰值、持续数、某一帧或整个区间的汇总方法。片头等快速切换片段可在不同时间点出现不同人数；边缘手指、背影、遮挡躯干是否计为可见人物也没有操作定义。相关诊断 flags：时间范围4项、遮挡5项、画质3项；flags可重叠，不等于这些项都裁为歧义。

其余6项裁决依据包含原帧中的边缘或遮挡人物可辨事实。不能把“没有正脸”自动等同于“没有人物”。下一轮若获准，应在标注前冻结人数时间聚合方式和局部身体计数准则；本轮不改标签或补规则重算。

## Action：分类 Schema 是否存在系统性歧义

21个差异中4项分类歧义、1项证据不足。歧义集中在：

1. **状态与事件混在同一集合。** 动作中的短暂直立、停步要不要额外计 sitting_or_standing；一方按主要事件，一方按所有姿态，两者可能均合理。ACTION_STATE_VS_EVENT出现3项。
2. **moving 没有范围。** 走动、头部转动、手臂操作及摄影机运动需要区分；当前未定义局部身体变化是否也记 moving。ACTION_MOVEMENT_SCOPE出现4项、ACTION_MOTION_VS_CAMERA_CUT出现2项；出现flag不自动撤销明确持物等事实。
3. **持有与操作的边界。** 提包、扶布料是否算 handling_object；仅携带与主动拿取是否区分。相关flag出现2项。
4. **说话与互动合并。** 14项涉及 ACTION_SPEECH_VS_VISIBLE。采样可支持可见口型变化或互动姿态，但不等于已确认可听说话、具体对白或 speaker；不能将 Action 裁决用于修复音频项失败。靠近、朝向是否已经构成互动仍可能歧义。
5. **躺卧缺少专类。** 2项涉及 ACTION_OTHER_LYING；躺姿只能落入宽泛other，并可能与其他动作并存。other不能提供一致的姿态粒度。

现有差异既有明确可见动作的遗漏，也有分类口径问题，不能全部归因于视觉模型错误。建议下一轮把姿态、位置移动、物体交互、可见交流分开定义，并规定集合的时间覆盖与完整性；这些只是待Review建议，没有改现有Schema或计分。

## Object：分类 Schema 的系统性歧义更明显

23个差异中16项被裁为分类歧义、6项证据不足，仅1项能明确判一侧正确。**本次差异子集支持“关键物体分类定义不充分”这一诊断，不支持把原低object F1全部解释为模型看错。**

- **关键性未定义：** OBJECT_KEYNESS_UNSPECIFIED出现17项。可见桌柜、毛巾、寝具或背景容器是否值得入标签，原规范没有可执行阈值；“看见”与“需要计为关键”被混合。明确有物体，不等于两套完整分类中必有一套唯一正确。
- **背景纳入未定义：** 相关flag15项。人物近景中的椅背、书架、瓶罐、灯具，一方全部记录、一方仅记录前景或操作物体，容易产生系统差异。
- **类别重叠：** 相关flag8项。容器与食物/饮品、手袋与容器、装裱文字与文档、灯具与设备等边界未固定；未知容器内容不能因类别推断成为事实。
- **other跨度过大：** 相关flag6项。毛巾、寝具、门牌、配饰等缺少共同粒度，短补充不参与原评分，集合无法说明两边究竟指哪个对象。
- **证据不足6项：** 原帧为特写、背景暗或被遮挡，部分物体用途与轮廓无法可靠确认；稀疏帧不足以证明整段不存在对象。必须保留为证据不足，不能强判一侧或剔除。

建议未来把可见物体存在性与关键性/显著性分开，明确背景纳入、容器/内容与重叠类别的多标签规则，保留不确定对象及时间溯源。该建议须新版本预注册后验证，不能事后套回本轮，把歧义裁决折算为正确来升级分数。
