# 屏中有伴｜完整视频分镜与 Remotion 制作说明

## 总体方向
- 画幅：1920×1080，16:9
- 30fps
- 当前主时间轴：0–10 秒
- 气质：高级、温馨、有陪伴感；深蓝内容世界逐步过渡到暖金色客厅
- 核心叙事：内容出现 → 内容生态扩展 → 镜头退出内容世界 → 揭示电视与真实客厅 → 背景柔化 → 品牌标题动态出现
- 不出现人物。
- 不做密集监控墙。
- 电视不要拉得过远，结束构图中电视仍应是明确视觉主体。

## 第一段｜0–3 秒｜已完成
沿用现有成片，不重做。

核心几何规则：
- 1、2、3 是三个全高竖向底层视频，分别占屏幕左/中/右 1/3。
- 4、5、6 分别覆盖 1、2、3 的上 1/3。
- 7、8、9 分别覆盖 1、2、3 的下 1/3，并逐个出现。
- 最终视觉形成 3×3：
  - 4｜5｜6
  - 1｜2｜3
  - 7｜8｜9
- 底层 1/2/3 不缩放、不移动、不重排。

## 第二段｜3–5 秒｜已完成
沿用现有成片，不重做。

从完整 3×3 开始：
- Camera Pull Back。
- 新内容从外围与 Z 轴空间自然增加。
- 大小、距离、层级不完全一致。
- 从规则九宫格过渡为非规则内容生态。
- 保持适度密度与留白，不形成素材墙/监控墙。

## 第三段｜5–10 秒｜本轮重点

### 5.0–6.5 秒｜内容世界开始收束
- 必须无缝承接第二段 5.0 秒最后一帧。
- Camera 继续后退，但不要再大量增加内容。
- 原本漂浮在纵深空间中的内容窗口逐渐向同一显示平面收束。
- 前后层级逐步压平，但过程要连续，不能突然变成二维拼贴。
- 让观众开始意识到“这个内容世界可能存在于某块屏幕里”。

### 6.5–7.5 秒｜电视边框 Reveal
- 随 Camera Pull Back，四周逐渐显露超窄电视边框。
- Reveal 应来自真实镜头后退，而不是直接叠一个电视 PNG。
- 屏幕内部内容继续播放/保持微动态。
- 电视边框出现后继续后退少量距离即可，不要把电视缩得过小。

### 7.5–8.5 秒｜温馨客厅建立
- 逐渐显露电视柜、墙面、局部沙发前景、茶几、绿植、暖色灯具等。
- 不出现人物、人物剪影或手持遥控器。
- 客厅为现代、精致、真实、温馨的夜间家庭空间。
- 暖金色间接照明为主，可保留少量来自电视的冷蓝色反光，形成冷暖平衡。
- 电视保持画面中心和主要视觉主体，整体镜头不要继续大幅拉远。
- 结束构图参考：电视约占画面宽度 45%–55%，能明确看见客厅但不会让电视变成远处小物件。

### 8.5–9.0 秒｜环境柔化，为标题让位
- Camera 基本停止。
- 客厅与电视内容逐渐进入柔和景深/高斯模糊状态。
- 不要整张图简单糊死：保留电视矩形轮廓、暖色灯光和空间结构。
- 可轻微降低背景对比度和饱和度，让文字成为视觉焦点。
- 暖金色光感开始增强，为标题动画蓄势。

### 9.0–9.6 秒｜主标题动态出现
主标题：
**屏中有伴**

设计要求：
- 不做普通字幕淡入。
- 标题居中偏上，尺寸明显大于副标题。
- 字体有高级品牌感，可采用现代宋体/具有书写张力的中文标题字体思路，但必须清晰、克制。
- 主色以暖白/浅金为主。
- 可带极轻微金色渐变、柔和高光，不做廉价金属 3D 字。

推荐动画：
1. 一颗细小暖金光点从左侧进入；
2. 光点沿一条优雅弧线/光丝划过画面；
3. 光丝经过的位置逐步 reveal “屏中有伴”；
4. 字体不是整体同时出现，可按字或按遮罩方向形成约 80–120ms 的轻微错峰；
5. 出现时 scale 可从约 0.97 → 1.00，同时 blur 由轻到清晰；
6. 光丝穿过标题后继续向右形成一条细而克制的尾迹；
7. 标题落定后保留非常轻的暖金呼吸光。

重点：文字动效要像品牌片片尾，不像 PPT 飞入或普通字幕。

### 9.6–10.0 秒｜副标题出现并定帧
副标题严格使用：

**重塑大屏内容发现，让每一次开机，皆有温度相伴。**

排版：
- 位于主标题下方。
- 字号明显小于主标题。
- 增大字距，形成高级、舒展的横向节奏。
- 可以使用极细横线/小光点作为装饰，但不能喧宾夺主。
- 不需要额外英文。

动画：
- 主标题基本稳定后再出现。
- 可使用从中心向左右展开的 mask reveal，或轻微 blur → clear。
- 副标题整体出现时间约 250–350ms。
- 与主标题错开，形成明确层级。
- 最后保持完整品牌定帧。
- 背景仍是温馨客厅的柔焦画面，金色光丝只做极缓慢余韵流动。

## 第三段关键视觉原则
1. 不出现人物。
2. 电视不拉得过远。
3. 客厅必须温馨，而非科技展厅或豪宅样板间。
4. 内容世界到电视屏幕的转换必须依靠 Camera Pull Back + 空间收束完成。
5. 8.5 秒以后背景逐渐柔化，视觉焦点从电视转移到品牌文字。
6. 标题必须有设计感和动画层次，不能只 opacity fade。
7. “屏中有伴”是第一视觉层级；副标题是第二层级。
8. 金色元素用于传递温度和陪伴，不做爆炸式粒子特效。
9. 最后定帧仍应隐约看出电视与家庭空间，不能变成纯色品牌页。

## 第三段建议镜头节点
- 5.0s：第二段内容世界最终状态
- 6.0s：内容纵深开始收束
- 6.8s：屏幕平面感明显
- 7.2s：电视超窄边框出现
- 8.0s：电视 + 温馨客厅基本完整
- 8.5s：Camera 停止，进入最终构图
- 8.8s：背景开始柔化
- 9.0s：金色光点/光丝进入
- 9.1–9.6s：“屏中有伴”完成 reveal
- 9.6–9.9s：副标题 reveal
- 9.9–10.0s：完整定帧

## 动效实现建议
Remotion 中建议将第三段拆成：
- ContentWorldCollapse
- TVReveal
- LivingRoomReveal
- BackgroundDefocus
- BrandTitleReveal
- BrandSubtitleReveal

所有 Camera / scale / position / blur / mask 动画统一使用连续 easing，避免段落之间产生机械断点。

文字动画优先使用 SVG mask、clip-path、blur、transform 与可控光丝路径；不要用简单的 CSS opacity 作为唯一动画。
