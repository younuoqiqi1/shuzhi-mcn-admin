# 屏中有伴｜第二段 3–5 秒 Remotion 任务说明

## 目标
承接已完成的 0–3 秒。第二段只制作 3–5 秒：从完整 3×3 九宫格自然扩展为更大的内容世界，并通过 Camera Pull Back 为下一段“电视机/客厅 Reveal”建立衔接。

## 起始状态
3.00s 必须无缝承接第一段最后一帧：中心是完整 3×3 九宫格，内容仍在播放。不要重新播放第一段，不要改变第一段既有动画。

## 核心视觉
这段不再按编号、规则网格继续扩展。3×3 之后进入“非规则内容生态扩展”：
- 镜头持续缓慢后拉，并逐渐增强 Pull Back。
- 新内容窗口从中心九宫格周围、画面边缘和纵深方向逐个出现。
- 新窗口大小不完全一致，前后层级、距离和出现时间有变化。
- 中心原始 3×3 在整个过程中保持可辨认，逐渐成为更大内容世界的一部分。
- 不做整齐的 5×5、6×6 网格，不做规则复制。
- 不做密集“监控墙”；要有留白、层次和纵深。

## 数量与密度
3.00s：9 个。
3.2–3.8s：外围开始出现少量新窗口。
3.8–4.4s：增长明显，同时镜头继续后拉。
4.4–5.0s：形成较丰富的内容空间。

最终可见窗口建议约 25–35 个，不追求越多越好。宁可通过纵深、边缘半露和 Camera Pull Back 表达“还有更多”，也不要把画面塞满几十个细小方格。

## 空间关系
- 原始 3×3 作为视觉锚点，位于中心区域。
- 新内容可以出现在中心外围、左右两侧、上下边缘以及更远的 Z 轴空间。
- 窗口允许有不同尺寸，但仍以 16:9 内容卡片为主。
- 可以有轻微透视角度和景深，近处卡片更大、远处更小。
- 不要让所有卡片都正对镜头、等距排列。
- 不要把中心九宫格突然打散。

## 建议节奏
### 3.00–3.20s
延续第一段完整 3×3，短暂稳定，让观众确认九宫格已经形成；镜头开始非常轻微后拉。

### 3.20–3.70s
第一批新内容从九宫格外围逐个出现。数量克制，先让观众感知“九宫格之外还有内容”。

### 3.70–4.20s
Camera Pull Back 加强；更多内容从左右、上下和后方逐步出现，形成前后层次。增长速度开始提高。

### 4.20–4.70s
内容生态进一步展开，画面从“一个九宫格”转变成“一个内容空间”。保持大小变化和间距，不规则但有视觉秩序。

### 4.70–5.00s
不要继续疯狂增加数量。重点转为镜头拉远和空间稳定，形成下一段可以继续拉出电视边框/客厅的构图。

## 动画要求
新窗口不要纯 opacity 淡入。可结合：
- mask / clip reveal
- 很轻的 scale
- Z 轴从远处进入
- 边缘滑入
- 轻微景深/模糊变化

运动需要有统一的 easing，避免每张卡片像 PPT 单独飞入。

Camera Pull Back 是本段主运动，内容增长是辅运动。观众首先应该感受到“视野越来越大”，而不是“屏幕上不断堆卡片”。

## 5 秒结束帧要求
5.00s 时：
- 已明显从 3×3 拉远到更大的内容空间；
- 中心仍能隐约识别最初九宫格；
- 可见内容丰富但不拥挤；
- 四周与纵深仍留有空间；
- 构图适合下一段继续 Pull Back，逐渐显露电视机边框和客厅环境。

本段不要提前出现电视机外框、客厅、Logo、品牌文字、金色爆燃或 Ambilight。

## 第一版验收
1. 是否与 0–3 秒无缝衔接；
2. 3×3 后是否从“规则增长”自然转成“非规则生态扩展”；
3. Camera Pull Back 是否成为主要视觉运动；
4. 是否有明显 Z 轴纵深，而非二维素材墙；
5. 最终是否控制在舒适密度，没有监控墙感；
6. 5 秒结束帧是否能自然衔接下一段电视/客厅 Reveal。
